# 앱 내려받기

안드로이드 휴대폰·태블릿용 설치 파일(APK)을 받는 곳입니다. 아이폰은 지원하지 않습니다.

| 앱 | 설명 | 내려받기 |
|---|---|---|
| **민턴매치** | 배드민턴 모임에서 참가자 등록, 코트 배정, 대진표를 한 화면에서 관리합니다. | [mintonmatch.apk](https://github.com/sooo0o0o/apps/releases/download/mintonmatch/mintonmatch.apk) |
| **모험일지** | 둘이 함께 쓰는 공유 캘린더입니다. | [couple-cal.apk](https://github.com/sooo0o0o/apps/releases/download/couple-cal/couple-cal.apk) |

## 설치 방법

1. 위 표에서 받을 앱의 파일 이름을 누릅니다.
2. 내려받기가 끝나면 알림이나 `내 파일` 앱에서 받은 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 `설정`을 눌러 이 브라우저의 설치를 허용한 뒤 돌아와 `설치`를 누릅니다. 처음 한 번만 필요합니다.

## 업데이트

새 버전이 나오면 같은 주소에서 다시 받아 설치하면 됩니다. 기존 앱을 지우지 않아도 되고, 저장된 데이터는 그대로 남습니다.

지금 올라와 있는 버전은 [Releases](https://github.com/sooo0o0o/apps/releases)에서 확인할 수 있습니다.
